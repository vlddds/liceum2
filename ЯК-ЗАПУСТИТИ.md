# Як запустити сайт Ліцею №2

## 1. Викласти в інтернет (безкоштовно)

**Найпростіше — Netlify Drop:**
1. Відкрийте https://app.netlify.com/drop і увійдіть (можна через Google).
2. Перетягніть у вікно всю папку сайту (`!site`).
3. Через хвилину з'явиться адреса на кшталт `https://licey2-pidgorodne.netlify.app`.
   Назву можна змінити: Site configuration → Change site name.
4. Щоб оновити сайт — знову перетягніть папку (Deploys → перетягнути).

**Або GitHub Pages:** створіть репозиторій, завантажте всі файли,
Settings → Pages → Branch: `main` → Save. Адреса: `https://ІМ'Я.github.io/НАЗВА/`.

**Власний домен** (наприклад `licey2.pidgorodne.ua`) підключається в налаштуваннях Netlify / GitHub Pages.

## 2. Після запуску: замінити SITE-DOMAIN

У файлах `*.html`, `sitemap.xml`, `robots.txt` є заглушка `SITE-DOMAIN`.
У VS Code: Ctrl+Shift+H → знайти `SITE-DOMAIN` → замінити на адресу без `https://`
(наприклад `licey2-pidgorodne.netlify.app`) → «Замінити все».

Потім додайте сайт у Google Search Console (https://search.google.com/search-console)
і надішліть карту сайту: `https://ВАША-АДРЕСА/sitemap.xml`.

## 3. Форми та відгуки в Google-таблицю

Інструкція — на початку файлу `tools/google-apps-script.gs` (≈5 хвилин).
Після цього «Швидке повідомлення» і «Відгуки» падатимуть у таблицю,
а відгук з'являється на сайті, коли ви ставите галочку «Схвалено».

## Де що редагувати

| Що | Файл |
|---|---|
| Контакти, анонси новин на головній, гуртки, фото каруселі | `js/data.js` |
| Новини | `js/sections/news.js` |
| Освітній процес, досягнення | `js/sections/education.js` |
| Публічна інформація | `js/sections/public.js` |
| Виховна робота, безпека, тривога | `js/sections/upbringing.js` |
| Харчування, меню, бібліотека, психолог | `js/sections/services.js` |
| Часті питання | `js/sections/faq.js` |
| Фотоальбоми | `js/sections/albums.js` |
| Вчителі | `js/teachers.js` |
| Історія, адміністрація, правила | `js/about.js` |
| Календар подій | `js/calendar.js` |
| Розклад уроків і дзвінків | `js/schedule.js` |
| Архів | `js/archive.js` |

Документи з Google Drive вставляються як `drive("ID")` — ID є в посиланні `drive.google.com/file/d/ID/view`.
Фото: покладіть файл у папку `img/…` і вкажіть шлях замість `""`.
